# История изменений

[English](CHANGELOG.md) | [Русский](CHANGELOG.ru.md)

Версии следуют Semantic Versioning. Все выпуски ниже — предварительные: это не
сертификация бухгалтерской корректности или совместимости настольных приложений.
Исторические этапы впервые публикуются 2026-10-26 с сохранением исходных коммитов.

## Не выпущено

- Добавлены пошаговые руководства EN/RU от выбора настольного приложения с ИИ до обнаружения семи скиллов и первой задачи; упрощены README и быстрый старт.
- В пакет включены оригинальная иллюстрация и редактируемые схемы EN/RU через список точных разрешённых путей, с тестами переносимости и отказов.
- Запрос одного небольшого шага теперь ограничивается до полного планирования регистрации; добавлены сценарии на двух языках, живые испытания Codex/Claude и оставшиеся пробелы приёмки.

## 0.8.0-preview.1

Предварительный выпуск комплекта скиллов жизненного цикла. Публикация требует проверок соответствующего тега и подтверждённых файлов; прежние опубликованные версии не меняются.

- Исправлен выбор источника старого комплекта: явно заданная папка используется независимо от её имени и наличия посторонней соседней папки.
- Общий вход и шесть предметных скиллов поставляются единым переносимым комплектом с общим профилем/доказательствами, полной установкой и проверками ресурсов вне исходников.
- Добавлена EN/RU-подготовка и продолжение: запуск, работа с клиентом, переписка, годовая готовность, сервисы, первый найм, изменения и закрытие.
- Реальный обзор и главная GUI показывают активные задачи, включая задачи без срока/других месяцев, зависимости и актуальность подтверждений. Продолжение в GUI готовит запрос ассистенту, не выполняя его.
- Добавлено ограниченное чтение ссылок отдельных XML Invoice/CreditNote с сохранением доказательств исправления. Проверка предоставленных выгрузок различает способ/отбор по датам и границы охвата; Lexware остаётся на локальных примерах.
- Уточнены консультации по источникам, необходимые дата/метод учёта и инструкции начала с задачи; налоговые формулы не добавлялись.
- Зафиксированы свежие синтетические испытания, обнаружение Codex CLI и явным маршрутом Claude Code, локальные runtime/package-проверки. Приёмка текущего ref на Windows 5.1/других платформах, обычными пользователями и в реальных сервисах остаётся открытой; см. [журнал](docs/validation.ru.md).

## 0.7.0-preview.1

Версия [0.7.0-preview.1](https://github.com/ilyafedotov-ops/german-business-skills/releases/tag/v0.7.0-preview.1). Загрузка требует успешных проверок платформ, публикации и проверки соответствующих файлов.

- Добавлен GUI настоящего рабочего пространства с навигацией EN/RU/DE, импортом
  и проверкой документов, личными черновиками и запросами помощи ассистенту.
- Подключены существующие проверяемые операции выбора учёта, денежных записей,
  сторно, связанных исправлений, отчётов периода и версий/доказательств подачи.
  Налоговый движок и отправка в ELSTER не добавляются.
- Добавлены полное копирование, проверка, восстановление и явные состояния ошибок.
- Локальные сессии защищены случайными ключами, проверками origin/host,
  идентичностью выбранного пространства и проверкой версий черновиков.
- Отдельные сборки Windows/macOS включают среду выполнения: пользователю не нужно
  устанавливать Python. Нативные сборки и проверки готовых программ включены в CI.
  Подпись ОС/нотариальное заверение и приёмка с пользователями остаются открытыми.
- Обновлены двуязычные быстрые старты, схемы, примеры папок и описания проекта.

## 0.6.0-preview.4

- Криптографическая проверка повторяется ограниченное число раз, если новая
  аттестация GitHub ещё недоступна. Проверка обязательна: постоянная ошибка
  останавливает процесс. Тесты проверяют отложенный успех и окончательный отказ.
- Preview.3 прошёл тесты, безопасность и сборку, опубликовал неизменяемый выпуск,
  но немедленная финальная проверка опередила доступность аттестации. Последующая
  проверка выпуска прошла. Существующие файлы и теги не заменялись.
- Сохранены статическая маршрутизация прототипа и полный порог серьёзности CodeQL.

## 0.6.0-preview.3

- Выбор экрана теперь явно задаётся статическими ветками без косвенного вызова.
- Сохранены исправления SARIF и браузерные регрессии preview.2. Его порог правильно
  заблокировал оставшееся предупреждение о косвенном вызове до публикации;
  preview.2 — неопубликованный тег кандидата, а не скачиваемый выпуск. Теги не меняются.
- Заменяет preview.1 и включает весь процесс проверяемых выпусков и
  самостоятельного учёта, описанный ниже.

## 0.6.0-preview.2

- Порог безопасности теперь читает серьёзность CodeQL из расширений SARIF и
  отвергает неизвестные правила. Сохранённый отчёт preview.1 теперь корректно
  блокируется на уровне 7.5; прежний успех проверки не означал чистый анализ.
- Исправлена маршрутизация вымышленного прототипа: фрагмент URL не может вызвать
  унаследованный метод объекта. Добавлены браузерные проверки таких ссылок.
- Push-проверки выполняются для main, а изменения рабочих веток — через PR без
  дублирования запусков. Выпуски по тегам сохраняют полный независимый набор проверок.
- Заменяет preview.1. Его ZIP-пакеты skill не содержат затронутый прототип, но
  исходники и старый порог безопасности не следует использовать как актуальную
  основу. Неизменяемые теги и файлы предыдущего выпуска сохранены.

## 0.6.0-preview.1

- Исправлен откат импорта Windows: окончательные метки времени читаются после закрытия записи; изменённые и заменённые файлы сохраняются.

- Единая проверяемая версия, архивы с номером выпуска, перечень хешей файлов и
  точный коммит исходников. Существующие данные рабочего пространства не мигрируют.
- Публикация после проверок Windows/macOS, PowerShell 5.1 и браузеров; закреплены
  версии Actions, добавлены проверки зависимостей и безопасности.
- Аттестации сборки GitHub и неизменяемые выпуски. Подпись подтверждает источник
  и неизменность байтов, но не отсутствие ошибок или налоговую корректность.
- Сохранён весь процесс самостоятельного учёта из 0.5.0-preview.

## 0.5.0-preview

Исторический снимок: `c4df69f`. Каталог и проверка документов, нормализация банковских
данных, ограниченный денежный журнал, подготовка и подтверждения ручной подачи в
ELSTER, локализованные папки, читаемые отчёты, руководства, реальный обзор и
проверенное резервное копирование. Windows без Python поддерживает приём документов,
обзор и восстановление; защищённые операции учёта и подачи требуют имеющегося Python.
Графический прототип по-прежнему работает с вымышленными данными.

Исторический выпуск только исходников, без заявления о новой аттестации сборки этого
коммита. Проверяемые пакеты и актуальный процесс сопровождения — в 0.6.0-preview.1.
