# Настоящий интерфейс рабочего пространства — 0.7.0-preview.1

[English](gui.md) | [Русский](gui.ru.md) | [Инструкция пользователя](../gui/README.ru.md)

Приложение `gui/` подключает браузерный интерфейс к операциям настоящего
рабочего пространства. Отдельный `prototype/` остаётся вымышленной демонстрацией.
Версия [0.7.0-preview.1](https://github.com/ilyafedotov-ops/german-business-skills/releases/tag/v0.7.0-preview.1)
добавляет отдельные пакеты Windows x64, macOS Apple Silicon и macOS Intel.
Используйте подходящий архив после публикации и проверки; локальная сборка или
успешный тест не равны опубликованному выпуску платформы. [Проверка загрузки](releases.ru.md)
и [инструкция приложения](../gui/README.ru.md) объясняют запуск без установки Python.

## Доступные действия

- Открыть/создать личную рабочую папку и выбрать навигацию на русском, немецком или английском.
- Импортировать выбранные PDF, XML, изображения и CSV; увидеть результат каждого
  файла, проверить каталог рядом с безопасным просмотром текста/изображения или скачать оригинал.
- Явно выбрать локальный учёт или существующую программу. Вносить проверенные
  денежные записи со строками и доказательствами, делать сторно/исправления без переписывания истории.
- Создавать фиксированные версии подачи, проверять препятствия, одобрять/разрешать,
  фиксировать ручную попытку, наблюдаемую квитанцию и ответы ведомства.
  Отмена/замена доступна только по правилам существующей модели состояний.
- Сохранять незаконченные формы отдельно как черновики и продолжать после перезапуска.
- Создавать отчёты периода/обзор и выполнять полное копирование, проверку и восстановление.

Интерфейс не добавляет налоговый движок, OCR, живые банковские/программные
коннекторы, отправку в ELSTER или фоновую службу напоминаний. Выбранная внешняя
программа остаётся основной. Проверка каталога не означает извлечение полей счёта
или проводку. Источники и технические ошибки могут оставаться на исходном языке;
шаблоны отчётов по-прежнему русские/английские.

## Поставка и безопасность

Приложение открывает обычный браузер и запускает службу с авторизацией только на
`127.0.0.1` и случайном порту. Нужен новый ключ сессии; проверяются точный host и
origin. Межсайтовый доступ не разрешён. Идентичность рабочей папки блокирует старые
формы после переключения в другой вкладке. Нативные диалоги используют фиксированные
команды платформы без подстановки пользовательского ввода. Удалённых ресурсов,
телеметрии и автоматических вызовов AI нет.

API передаёт изменения существующим проверяемым операциям с сохранением оригиналов,
хешей, блокировок и истории. Формы — отдельные черновики с проверкой версий и
завершённых контрольных записей истории, не бухгалтерские записи. Оригиналы доступны
только через защищённый API документов, а не публичный файловый сервер. HTML
скачивается и не выполняется внутри приложения. Браузер не хранит деловые формы;
явно сохраняйте их в рабочую папку перед закрытием.

[PyInstaller](https://pyinstaller.org/en/stable/) — **зависимость только для сборки**:
платформенные пакеты включают интерпретатор существующего движка. Пользователь Windows
не устанавливает Python. Версии инструментов сборки закреплены с хешами колёс.
Для Windows x64, macOS Apple Silicon и macOS Intel отдельные задачи CI; процесс
требует успешной проверки готовых программ с пустым `PATH`. Это не означает перенос
расширенного учёта на штатный PowerShell.

Переносимые ZIP skill сохраняют повторяемость. Архивы GUI содержат перечень файлов/
ссылок и контрольную сумму; побайтовая повторяемость нативных сборок не заявляется.
Процесс выпуска включает эти архивы в проверку происхождения и неизменяемый выпуск.
Подписи Authenticode/Apple Developer ID и нотариальное заверение не настроены.
Блокировка политикой ОС не разрешает отключать защиту. Приёмка первого запуска
с нетехническими пользователями остаётся необходимой.

## Работа разработчика

С уже доступным Python запустите `python3 -B gui/server.py`: браузер откроется
автоматически. Пользователю готового пакета эта команда не нужна.
`--root /absolute/private/workspace` открывает существующую папку.
`--no-browser` используется тестами и печатает временный ключ сессии; не публикуйте его.

```sh
python3 -B -m unittest discover -s tests -p test_gui_server.py -v
npm run test:gui -- --browser=chromium
npm run test:gui -- --browser=webkit
```

В отдельной среде сборки установите инструменты командой
`pip install --require-hashes -r tools/gui-build-requirements.txt`, затем:

```sh
python3 -B tools/build_gui.py --output /absolute/new/gui-app
python3 -B tests/gui-packaged-smoke.py --executable /absolute/new/gui-app/GermanBusinessKit
python3 -B tools/package_gui.py --bundle /absolute/new/gui-app --output /absolute/new/gui-archives
```

В Windows используйте `GermanBusinessKit.exe`. Собирайте на каждой целевой ОС:
PyInstaller не является кросс-компилятором. [Официальная документация сборки](https://pyinstaller.org/en/stable/usage.html),
проверена 26.10.2026. [Архитектуры GitHub runners](https://docs.github.com/en/actions/reference/runners/github-hosted-runners)
определяют метки CI, а не приёмку desktop-приложения. Фактические результаты
записываются отдельно в [журнале проверок](validation.ru.md).
