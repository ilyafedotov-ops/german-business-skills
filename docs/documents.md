# Readable reports and documents to send

[English](documents.md) | [Русский](documents.ru.md)

Ask naturally: “Prepare a report for October,” “Draft a response to this letter,” or “Prepare the attachments and explain what I will submit.” You do not need to choose a technical format or edit JSON.

The assistant prepares a readable result in your language, with its period, evidence, unresolved questions and next step. A German recipient document can be accompanied by a separate Russian explanation. Private review notes and local file paths are not automatically sent to the recipient.

| What you need | Result |
| --- | --- |
| Understand your records | Readable report with tables, coverage and open questions |
| Fill an official form | Field worksheet and review of the actual current portal/software draft |
| Send an explanation or requested evidence | Recipient document, selected attachments and a private review sheet |
| Resume later | Saved version, sources, actual sending state and next action |

A standalone HTML file opens in an existing browser on Windows/macOS. A PDF is produced through an available export/print facility and checked after creation; DOCX/XLSX are options when suitable tools exist. No Python installation is required to read HTML or use the existing browser's PDF facilities. If export is unavailable, you receive the readable source with the remaining step explained; the assistant must not claim a PDF was created.

Tax documents belong under the localized tax area for their year, internal reports under accounting reports, and general correspondence under business correspondence. Files receive understandable names and versions. Existing originals and submitted versions stay preserved. Changing a folder or filename does not change approval or submission status.

A PDF is not automatically an official return or an accepted attachment. The assistant checks the exact recipient/form and current route. [ELSTER distinguishes dedicated forms from general messages](https://www.elster.de/eportal/formulare-leistungen/alleformulare/eingsonstnachr); supporting evidence and the tax return are separate tasks. See [dated source research](../skills/de-business-kit/references/document-delivery-sources.md).

Implemented here: skill instructions, EN/RU report/review templates, a German letter template and a static printable HTML template. Several commands still output technical JSON; the assistant supplies the readable explanation. This does not add automatic PDF/DOCX export on every host, native advanced accounting writers or ELSTER transmission. Draft, reviewed, authorized, submitted and authority response remain separate, evidenced states.
