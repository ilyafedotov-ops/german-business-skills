# Папки рабочего пространства и язык

[English](folder-structure.md) | [Русский](folder-structure.ru.md) | [Deutsch](folder-structure.de.md)

Проверено 2026-10-25. Сейчас технические папки имеют английские имена, даже если помощник общается по-русски. Немецкий язык поддерживается не во всех командах и отчётах; некоторые части используют английский. Полной локализации пока нет.

Особенно непонятно различие между `04_accounting` и `06_bookkeeping`: пользователю трудно решить, куда положить счёт. Входящие спрятаны в `00_admin/inbox`, а технические файлы профиля и истории не должны становиться повседневными задачами пользователя.

Уже исправлено: новое рабочее пространство больше не создаёт сразу двенадцать месяцев с тремя подпапками в каждом. Месяц и папка оригиналов появляются при добавлении документа. Это убирает 49 пустых каталогов при первом запуске. Существующие папки и файлы не удаляются.

## Предлагаемые разделы

| Папка | Для чего |
| --- | --- |
| `01 Входящие` | Смешанные документы, которые ещё нужно разобрать |
| `02 Документы` | Сохранённые оригиналы и связанные результаты обработки |
| `03 Учёт` | Выписки, бухгалтерские записи и отчёты |
| `04 Налоги` | Декларации, налоговая переписка и подтверждения отправки |
| `05 Бизнес` | Регистрация, договоры и прочая деловая переписка |

Это **предложенные названия**, текущие программы ещё не записывают данные по этим путям. Нужно выбрать: переводить реальные папки в Проводнике/Finder для новых пространств либо использовать эти названия только в интерфейсе и руководстве. Физический перевод требует единого проверенного сопоставления путей для всех инструментов.

Создавать подпапки стоит только по мере необходимости. Документы можно упорядочивать по `ГГГГ/ММ`, затем `Оригиналы` и `Обработанные`. Название месяца показывается в интерфейсе. Месяц хранения не определяет налоговый период. Исходные имена и содержимое документов сохраняются; понятные заголовки задаются в каталоге. Один оригинал может относиться к нескольким задачам без создания копий в разных папках.

Профиль, индексы, историю и настройки следует выделить в техническую область. Это не защита доступа; она обязательно входит в резервные копии. Новому пользователю не нужно заранее решать налоговую категорию документа: сначала можно принять смешанные файлы, а невыясненные вопросы оставить открытыми.

Основная работа — самостоятельный учёт. Необязательные выгрузки относятся к отчётам; передача бухгалтеру не должна определять структуру. Проверка документа, бухгалтерская запись, подготовка декларации, отправка и ответ Finanzamt — разные состояния.

## Существующие данные

Не переименовывайте текущие технические папки вручную: сохранённые ссылки могут перестать работать. Будущая миграция должна иметь предварительный просмотр, проверенную резервную копию, проверку конфликтов имён, переназначение ссылок и контроль хешей оригиналов.

Язык папок нужно хранить отдельно от языка общения. Переход на русский не должен переименовывать ранее созданный немецкий архив. Официальные немецкие названия форм сохраняются точно, с объяснением на выбранном языке.

Критерий готовности: пользователь на русском или немецком может начать работу, добавить смешанные файлы и продолжить позже без английских подсказок; Windows и macOS используют одинаковые правила; переключение языка и работа со старым архивом не меняют оригиналы.

В этом изменении реализовано только создание месяцев по необходимости. Перевод реальных папок, миграция и перевод прототипа ещё не реализованы. Подробный [технический обзор](folder-structure.md) содержит таблицу английских, русских и немецких названий.
