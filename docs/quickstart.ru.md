# Быстрый старт: первый ответ

[English](quickstart.md) · **Русский**

Впервые пользуетесь ИИ-помощником? **[Откройте пошаговое руководство с иллюстрациями](../skills/de-business-kit/guides/install.ru.md)**. Оно объясняет каждый шаг ниже: со ссылками на загрузку, готовым сообщением для настройки и проверками перед продолжением.

1. **Выберите одно приложение.** Codex — помощник OpenAI; Claude Code — Anthropic. Они работают с локальными файлами и используют специализированные инструкции — скиллы. German Business Kit добавляет семь скиллов для жизненного цикла бизнеса.
2. **Установите приложение и войдите.** Используйте [официальную настройку Codex](https://learn.chatgpt.com/docs/app) или [Claude](https://code.claude.com/docs/en/desktop-quickstart). Откройте **Codex** либо Claude **Code → Local**. Проверьте доступ аккаунта до покупки подписки.
3. **Создайте папку проекта.** В Проводнике/Finder создайте **Business Assistant** в приватном месте. Откройте эту папку как локальный проект приложения.
4. **Скачайте набор скиллов.** В [Assets выпуска 0.8.0-preview.1](https://github.com/ilyafedotov-ops/german-business-skills/releases/tag/v0.8.0-preview.1) выберите `-codex.zip` или `-claude.zip` и `SHA256SUMS`. Файлы `-gui-` — необязательное приложение для записей.
5. **Проверьте и установите.** Используйте [готовое сообщение настройки](../skills/de-business-kit/guides/install.ru.md#5-попросите-помощника-установить-семь-скиллов). Оно просит проверить загрузку и поместить все семь полных папок скиллов в `.agents/skills` проекта для Codex или `.claude/skills` для Claude Code, сохраняя существующие файлы.
6. **Откройте новый разговор в том же проекте.** Выберите `de-business-kit`; в Claude Code используйте `/de-business-kit`. Спросите, какие скиллы набора действительно доступны. [Проверка обнаружения и помощь](../skills/de-business-kit/guides/install.ru.md#6-откройте-новый-разговор-и-проверьте-скиллы).
7. **Отправьте небольшой запрос:**

> Используй de-business-kit. Я только пробую помощника на вымышленном примере: хочу начать работать переводчиком в Германии. Пока не знаю, с чего начать. Помоги выбрать один небольшой первый шаг.

![Открыть помощника, добавить семь скиллов, задать один вопрос](../skills/de-business-kit/guides/images/setup-map.ru.svg)

**Успех:** вы получили одно понятное действие и знаете, что делать дальше. Для простого вопроса не нужны выбор учётной системы, настоящие документы и рабочее пространство бизнеса. Можно писать на русском или английском.

Когда понадобится сохранить работу, попросите отдельную приватную папку бизнеса и понятную заметку для продолжения. В следующий раз откройте тот же проект помощника и попросите продолжить с этой заметки. До использования настоящих личных документов выясните, что будет передаваться ИИ-сервису.
