# Начало работы

[English](quickstart.md) | [Русский](quickstart.ru.md)

Откройте [«Начните здесь»](../skills/de-business-kit/guides/start.ru.md): пять шагов от первого сообщения до сохранённого результата. Для регулярной работы используйте [руководство пользователя](../skills/de-business-kit/guides/user-guide.ru.md).

| Что вам нужно сейчас | Куда перейти |
| --- | --- |
| Начать или попробовать на вымышленных данных | [Краткий старт](../skills/de-business-kit/guides/start.ru.md) |
| Разобраться с ежедневной работой или ошибкой | [Руководство пользователя](../skills/de-business-kit/guides/user-guide.ru.md) |
| Подключить скачанный проект | [Варианты установки](../README.ru.md#установка) и [пакеты и обновления](distribution.ru.md); технические действия может выполнить помощник |
| Начать в Windows без Python | [Windows](windows.ru.md) |
| Найти документы по конкретной теме | [Оглавление](index.ru.md) |

Выберите уже используемое приложение и одну небольшую задачу. Рабочие документы храните отдельно от проекта. Установленный skill не даёт доступ к почте или банку сам по себе. Не нужно заранее выбирать все бухгалтерские категории, изучать команды или проходить полную настройку ради простого вопроса.

В устанавливаемом пакете краткий старт и руководство находятся внутри `skills/de-business-kit/guides/`; они не требуют открытия репозитория. В новой рабочей папке есть отдельная короткая памятка. Старые рабочие папки при обновлении не переписываются.

[Фактические проверки и ограничения](validation.ru.md) отделены от инструкций: описание шага не доказывает его работу во всех версиях Windows/macOS и AI-приложений.
