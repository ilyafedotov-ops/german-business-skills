## Реальный обзор и восстановление (26.10.2026)

Реализован общий обзор EN/RU: выбранная система учёта и денежные записи периода, открытые/отложенные вопросы, замечания проверки подач, даты ответов ведомства с источниками и следующий шаг. Неизвестный результат отправки остаётся видимым при смене месяца. Генерация удерживает блокировку и не меняет основные записи учёта. Нативные средства Windows создают отдельный обзор HTML/Markdown/JSON без Python. Проверяются сохранённое состояние, контрольные суммы/история учёта и локальные доказательства; полная нативная проверка подачи и защищённые изменения журнала/подач пока недоступны. Реализованы полное резервное копирование, проверка и восстановление средствами Python и PowerShell с общим форматом манифеста, сохранением байтов оригиналов, новыми папками назначения, проверкой путей/коллизий и блокировками. Регрессионные тесты покрывают изменения источника, повреждённые копии и конкурентную запись. Независимая проверка выявила и помогла исправить блокировку восстановления, согласованность идентификатора копии, пустые коллекции и сериализацию времени в нативном коде.

С `GBK_TEST_DOCKER_IMAGE=mcr.microsoft.com/dotnet/sdk:9.0` та же команда — **206 успешно, без пропусков**, включая восстановление копий между Python и PowerShell. Стиль Python-обзора сохранён; это не новый дизайн GUI и не проверка по утверждённому визуальному эталону.

## Практические ограничения

Атомарная замена JSON защищает отдельный файл, но копии, индекс, история и события не объединены в одну транзакцию. Жёсткое прерывание может оставить обнаруживаемый файл вне индекса или отсутствие события после обновления индекса. Проверяйте состояние перед повтором. Блокировки координируют эти утилиты, а не произвольные внешние редакторы. Хеши не являются подписями и не создают защищённый от изменений архив. POSIX-права применяются по возможности; Windows ACL, шифрование и резервирование зависят от среды пользователя.

README задаёт порядок установки: сначала создать новую личную рабочую папку, затем устанавливать skill для проекта внутрь неё. Установка для пользователя возможна до инициализации.
