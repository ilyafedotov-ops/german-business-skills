## Выполняйте подходящие проверки

Из checkout, с существующим runtime разработчика:

```sh
python3 -B tools/check_package.py
python3 -B -m unittest discover -s tests -v
git diff --check
```

Дополнительные проверки выбираются по изменённой области в [AGENTS.md](../AGENTS.md#validation-and-delivery): native Windows, обзор, восстановление, GUI, печатные документы, испытания скиллов или упаковка. Для документации нужны проверки пакета/ссылок/якорей/паритета; перенос ресурсов требует также detached-package проверки. Собирайте в новую абсолютную папку вне checkout. Node/Playwright и Python разработчика не являются требованиями к пользователю.

Native Windows требует Windows PowerShell 5.1 на Windows; PowerShell на macOS/Linux не эквивалентен. Свежий сеанс испытания скилла должен фиксировать хост/версию, реальные инструменты и наблюдаемые результаты без раскрытия критериев модели. Успешный тест, загрузка CI, health endpoint или аккуратный файл не подтверждают внешнее действие.
