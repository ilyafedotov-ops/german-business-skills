# Попробуйте рабочее пространство с пошаговыми подсказками

[English](prototype.md) | [Русский](prototype.ru.md) | [Документация](index.ru.md)

Откройте [интерактивную демонстрацию](../prototype/index.html) в современном браузере. Если репозиторий скачан ZIP-архивом, сначала распакуйте его, откройте папку `prototype` и дважды нажмите `index.html`. Файлы `index.html`, `style.css`, `state.js` и `app.js` должны оставаться вместе. Для запуска в Windows или macOS не нужны Python, Node, терминал, установка приложения или вход в аккаунт.

Это **интерактивный прототип с вымышленными данными**, отдельный от установленного навыка и вашего рабочего пространства. Не вводите реальные сведения о бизнесе. Интерфейс пока на английском; руководство доступно на английском и русском.

## Четыре сценария

1. На Home выберите **Organize existing records**. Просмотрите пример папки, выберите файлы, проверьте список и добавьте их. Один неподдерживаемый пример явно исключён. Реальная папка не открывается, данные не загружаются.
2. Откройте **Documents → Review invoice**. Сравните предложенную сумму с оригиналом примера, исправьте `119.00` на `119.80` или `119,80`. Категорию можно оставить невыясненной. **Save draft** сохраняет черновик; **Mark document reviewed** проверяет поля по источнику примера. Ни одно действие не создаёт бухгалтерскую запись.
3. Откройте **This month → Investigate payment**. Сравните строку выписки на €12 с возможным чеком. Добавьте заметку, оставьте вопрос открытым или свяжите примеры. Платёж не выполняется, бухгалтерская запись не создаётся.
4. Закройте вкладку, снова откройте тот же файл в том же браузере и выберите **Continue where I stopped**. Исправления и заметки восстановятся. Прерванный просмотр папки сохраняет этап и выбранные файлы.

Основные экраны: Home, Documents, This month, Taxes and letters, Accounts and services. Настройки и диагностика отделены от повседневной работы. На узком экране навигация переносится на несколько строк, а оригинал документа расположен над формой проверки.

## Подсказки и сохранение

Краткие инструкции находятся рядом с полями; подробности можно раскрыть. **Help me with this** открывает запрос с контекстом задачи, который можно скопировать в используемого помощника. Автоматической отправки нет. Перед подключением нужно определить точный продукт и доступные возможности; прототип не подключает Gmail, Lexware, sevdesk, WISO, банк или страховую компанию.

Изменения сохраняются только в локальном хранилище браузера. Надпись «Saved on this browser» появляется после успешной записи. Если запись не удалась или другая вкладка изменила данные, текущий ввод остаётся видимым с предупреждением: он не сохранён. Скопируйте его перед закрытием. Очистка данных, другой браузер, приватный режим или перемещение файлов могут помешать восстановлению. Это не шифрованное хранилище, синхронизация или резервная копия.

**Settings → Reset fictional demo data** запрашивает подтверждение замены сохранённых данных демонстрации. Реальные файлы и рабочее пространство навыка не меняются. Поведение хранения при открытии файлов ещё требует проверки на реальных устройствах пользователей.

## Что ещё предстоит реализовать

Предпросмотр — вымышленный HTML-документ, не PDF-просмотрщик или OCR. Импорт выбирает примеры, а не читает файловую систему или банковский CSV. Taxes and letters показывает этапы, но не редактирует декларацию и не передаёт её через ELSTER. Сравнение услуг готовит запрос помощнику, а не актуальный рейтинг или покупку. Производственная оболочка приложения и среда выполнения не выбраны.

Следующий этап — модерируемое исследование с нетехническими пользователями Windows/macOS, затем производственный интерфейс поверх проверенных команд рабочего пространства. Автоматические тесты браузера не заменяют такое исследование. См. [исследование дизайна](research/gui-ux-recommendation.md) и [проверки](prototype-validation.ru.md).

## Только для разработчиков

Пользователям эти команды не нужны. Для проверок используются Node 22 и зафиксированная версия Playwright как зависимость разработки:

```text
npm ci --ignore-scripts
npx playwright install chromium webkit
npm test
npm run test:browser
npm run test:browser -- --browser=webkit
```

Тесты открывают HTML-файл напрямую. Снимки сохраняются в исключённой из Git папке `output/prototype/`. Прототип не добавляет производственных зависимостей и не выполняет сетевых запросов. Пакеты навыка остаются отдельными.


Для настоящих записей используйте [создаваемый обзор рабочего пространства](document-workflow.ru.md), а не этот прототип. Оба реальных генератора читают основные файлы и создают статические снимки; кнопки прототипа не становятся действиями учёта. См. [текущее состояние](project-status.ru.md).
