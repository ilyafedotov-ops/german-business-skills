# Business Changes

Read the [shared context and execution contract](../de-business-kit/references/shared-context.md)
on direct entry. This skill ships with the complete German Business Kit bundle;
shared resources remain in the sibling `de-business-kit` directory. Read only
references relevant to the task. Use the user's language and saved context.

Use [changes and closure](../de-business-kit/references/changes.md). Establish
what is changing, which activities/entities it affects, intended versus actual
dates, existing decisions and outstanding obligations. Never equate one activity
closing with the entrepreneur or every registration ending.

Build an evidence-linked before/after plan with affected authorities, documents,
contracts, systems, periods and dependencies. Verify current primary sources and
competent local routes; do not reuse a fixed registration/closure sequence.

- Activity/address changes: preserve old facts and effective dates; distinguish
  declared plans from verified authority outcomes.
- Hiring or legal-form transitions: prepare facts, questions and a suitable
  execution route; do not claim payroll or corporate accounting is implemented.
- Accounting migration: preserve external authority and history; do not bypass
  protected configuration changes or duplicate records in a local shadow ledger.
- Pause/closure: account for outstanding payments, documents, reporting, responses
  and access. Back up before separately authorized migration; never delete records
  or cancel services merely because the user asks for a plan.

Use `de-business-tax` for reporting/authority questions and `de-business-services`
for contract/access changes. Return a readable ordered action plan and prepared
materials; mark completion only with actual evidence, retaining follow-up tasks.
The skill can be invoked directly without starting the router or monthly workflow.
