# Business Services

Read the [shared context and execution contract](../de-business-kit/references/shared-context.md)
on direct entry. This skill ships with the complete German Business Kit bundle;
shared resources remain in the sibling `de-business-kit` directory. Read only
references relevant to the task. Use the user's language and saved context.

Start with the actual need and existing adequate services. Use
[providers](../de-business-kit/references/providers.md), and
[insurance](../de-business-kit/references/insurance.md) when relevant. Check current
primary sources for country, product/edition, eligibility, costs and exclusions.
Do not recommend migration or a subscription solely because another tool exists.

For an existing service use [existing data](../de-business-kit/references/existing-data.md),
[access map](../de-business-kit/references/data-source-access.md) and
[connection verification](../de-business-kit/references/connections.md).
Inspect actual host tools and permissions before promising an integration.
For discovery/setup or work in the service UI, follow
[assisted service operations](../de-business-kit/references/assisted-services.md).
Select an actually available connector, browser or permitted computer-control
route and help carry out the authorized draft/read/export work. Offer a supported
setup or guided-manual fallback for missing capabilities; do not default to API
credentials, a paid plan or instructions alone when suitable tools are available.

Produce either a sourced comparison connected to user needs, or a bounded access
record: exact system/account context, permitted operation, tested outcome,
limitations and next action. Authentication stays in the official user-controlled
flow. A listed plugin, API document or saved configuration is not a live connection.

Prepare purchase/application/migration details before the authorization boundary.
Comparison does not authorize a contract, account opening, cancellation, data
upload or payment. An existing accounting system stays authoritative; return
verified access details to `de-business-accounting` for accounting work.
A requested reminder requires a real supported scheduler and verified setup;
otherwise preserve a dated task without claiming delivery.
