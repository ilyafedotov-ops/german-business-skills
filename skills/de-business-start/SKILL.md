# Business Start

Read the [shared context and execution contract](../de-business-kit/references/shared-context.md)
on direct entry. This skill ships with the complete German Business Kit bundle;
shared resources remain in the sibling `de-business-kit` directory. Read only
references relevant to the task. Use the user's language and saved context.

Establish the intended activity, existing activities, actual/planned start,
location and the requested result. Do not require an accounting choice or a
workspace merely to explain the next step.

1. Read [formation](../de-business-kit/references/formation.md) for the registration
   journey and [launch planning](../de-business-kit/references/launch-plan.md) for
   options, dependencies and forecast inputs. Ask only decisive missing facts.
2. Use [classification](../de-business-kit/references/classification.md) when the
   activity is unclear; preserve existing VAT/election history across activities.
3. For actual forms use [forms](../de-business-kit/references/forms.md). Find the
   current official form/help for the case before proposing exact fields. With
   no browser, prepare a worksheet and manual steps; no invented filled portal.
4. Prepare a readable launch/registration plan, reviewable activity description,
   known form inputs and unresolved choices. Keep estimates labelled and use
   [source-led estimation](../de-business-kit/references/tax-estimates.md).
5. Record preparation, authorized submission and observed registration separately.
   Keep follow-up questions and dependencies after the initial application.

Use `de-business-services` for needed services and `de-business-tax` for a
substantive tax choice. Return to the registration task with their findings;
classification uncertainty need not block independent factual preparation.
