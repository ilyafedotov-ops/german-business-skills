# Первый запуск — шаг за шагом

[English](install.en.md) · **Русский**

Это руководство проведёт вас от выбора приложения с ИИ до первого полезного ответа. Начать можно без программирования, команд в терминале, Python и бухгалтерской программы. Нужны компьютер с Windows или Mac, интернет и аккаунт с доступом к одному из приложений ниже. Для первой пробы используйте вымышленные данные.

![Предприниматель превращает идею в документы и следующие шаги](images/entrepreneur-journey.png)

*Иллюстрация, а не снимок экрана приложения.*

## 1. Выберите одно приложение

**Codex** и **Claude Code** — ИИ-помощники, которые умеют работать с файлами на вашем компьютере и применять специализированные инструкции. **Скилл** — набор инструкций и материалов для помощника. **German Business Kit** содержит семь связанных скиллов для открытия и ведения бизнеса в Германии.

Нужно **одно** поддерживаемое приложение. Выберите то, к которому у вас уже есть доступ. Если нет ни одного, проверьте доступность нужного режима до оформления подписки.

| Выбор | Откуда начать | Что открыть после входа |
| --- | --- | --- |
| OpenAI / Codex | [Официальная загрузка и настройка приложения](https://learn.chatgpt.com/docs/app) | Режим **Codex** в настольном приложении. Текущая документация называет приложение **ChatGPT desktop**; в некоторых версиях и на страницах загрузки ещё используется название **Codex**. |
| Anthropic / Claude Code | [Официальная загрузка и настройка Claude](https://code.claude.com/docs/en/desktop-quickstart) | **Code** в боковой панели Claude, затем локальная среда **Local**. |

Доступ и лимиты Codex зависят от аккаунта и политики организации. Для Claude Code в настольном приложении сейчас нужен Pro, Max, Team или Enterprise. Возможность пользоваться обычным чатом сама по себе не означает доступ к Code. Скиллы не включают подписку на ИИ и аккаунты сервисов. Инструкции провайдеров проверены **26.10.2026**; актуальные требования к компьютеру и доступу смотрите на официальной странице загрузки.

**Шаг завершён, когда:** вы выбрали одно приложение и убедились, что ваш аккаунт позволяет использовать локальный режим Codex/Code.

## 2. Установите приложение и войдите

1. Откройте официальную ссылку для выбранного приложения из таблицы выше.
2. Выберите загрузку для **Windows** или **macOS**. Если нужно выбрать тип Mac, откройте меню Apple → **Об этом Mac** и проверьте, указан Apple Silicon или Intel.
3. Откройте скачанный установщик и следуйте инструкции провайдера. На Mac перенесите приложение в **Программы**, если установщик предлагает это; на Windows выполните шаги установки.
4. Запустите приложение из **Программ** на Mac или меню **Пуск** на Windows.
5. Войдите через официальный экран аккаунта. Если откроется браузер, завершите вход там и вернитесь в приложение.
6. Откройте **Codex** либо **Code → Local** в Claude. Для этого пути терминальная версия приложения не нужна.

Если компьютер или организация блокирует установку, используйте разрешённый способ. Не отключайте защиту. Пароли и коды подтверждения вводите на экранах входа, а не в чате.

**Шаг завершён, когда:** вы можете начать локальный разговор в Codex/Code. Если видны только обычный Chat или Cowork, сначала проверьте требования к приложению и аккаунту.

## 3. Создайте и откройте проект помощника

1. В **Проводнике** Windows или **Finder** на Mac создайте папку **Business Assistant** в приватном месте на компьютере. Пока в ней будет только установка скиллов, без настоящих счетов и личных документов.
2. В Codex откройте или выберите эту локальную папку как проект и начните **New chat**. Название элемента выбора папки зависит от версии; убедитесь, что выбран проект **Business Assistant**.
3. В Claude **Code → Local** откройте элемент выбора папки проекта → **Open folder…** и выберите **Business Assistant**.
4. Если приложение просит доверить ему папку или разрешить доступ, подтвердите именно созданную папку.

**Шаг завершён, когда:** разговор связан с **Business Assistant** на этом компьютере. Просто написать название папки в обычном чате недостаточно, чтобы дать доступ к ней.

![Три шага: открыть проект помощника, добавить семь скиллов, задать один вопрос](images/setup-map.ru.svg)

*Схема процесса; расположение кнопок и экраны приложений здесь не изображены.*

## 4. Скачайте German Business Kit

1. Откройте [выпуск проекта 0.8.0-preview.1](https://github.com/ilyafedotov-ops/german-business-skills/releases/tag/v0.8.0-preview.1).
2. Если список файлов скрыт, раскройте **Assets**. Выберите один архив скиллов:
   - Codex: **`de-business-kit-0.8.0-preview.1-codex.zip`**.
   - Claude Code: **`de-business-kit-0.8.0-preview.1-claude.zip`**.
3. Скачайте **`SHA256SUMS`** из того же выпуска в ту же папку. Это список контрольных сумм для выявления повреждённого или изменённого файла.
4. Сохраните оба файла рядом. Архивы с `-gui-` — отдельное необязательное приложение для записей; архивы **Source code** относятся к другому способу установки.

На следующем шаге помощник проверит выбранный архив до использования его содержимого. Совпадение контрольной суммы проверяет целостность файла; проверка выпуска и происхождения сборки проверяет источник. Это разные проверки. [Полная процедура](https://github.com/ilyafedotov-ops/german-business-skills/blob/main/docs/releases.ru.md) доступна помощнику или техническому специалисту.

**Шаг завершён, когда:** у вас есть нужный ZIP и `SHA256SUMS` из указанного выпуска. Это новое руководство может описывать документацию из исходников, ещё не включённую в неизменяемый выпуск; структура каталогов семи скиллов совпадает.

## 5. Попросите помощника установить семь скиллов

В разговоре проекта **Business Assistant** предоставьте доступ только к скачанным ZIP и `SHA256SUMS`: через элемент доступа к файлам либо укажите полные локальные пути и разрешите конкретный запрос доступа. Вложение в чат само по себе может не давать доступа к локальному файлу. На Windows нажмите правой кнопкой на файл → **Копировать как путь**; на Mac выберите файл в Finder, удерживайте **Option** и в меню **Правка** выберите **Скопировать … как путь**.

Скопируйте сообщение, добавив два пути и выбранное приложение:

> Я настраиваю German Business Kit в этом локальном проекте Business Assistant, в [Codex / Claude Code]. Скачанный ZIP находится здесь: [полный путь к ZIP], а SHA256SUMS здесь: [полный путь к файлу контрольных сумм]. До использования содержимого проверь ZIP по соответствующей контрольной сумме. Если нужные средства проверки уже доступны, проверь происхождение выпуска для репозитория ilyafedotov-ops/german-business-skills и тега v0.8.0-preview.1 по процедуре https://github.com/ilyafedotov-ops/german-business-skills/blob/main/docs/releases.ru.md; точно укажи, что проверено, а что нет. При провале проверки остановись. Распакуй в новую папку. Изучи пакет, затем установи все семь полных папок скиллов в .agents/skills этого проекта для Codex или .claude/skills для Claude Code. Используй существующий поддерживаемый установщик, если он доступен, либо скопируй полные папки штатными средствами. Сохрани существующие файлы; если место назначения уже занято, остановись. Не устанавливай среды выполнения, не меняй параметры безопасности и глобальные настройки приложения. Покажи семь установленных названий, место установки и объясни, как начать новый сеанс.

Приложение может запросить чтение файлов или запись каталогов скиллов. Убедитесь, что пути соответствуют вашей загрузке и проекту **Business Assistant**. Если доступа к файлам нет, используйте [ручной вариант](#ручной-вариант). При отсутствии средств проверки происхождения нельзя называть совпадение суммы проверенной подписью; если вам нужна такая гарантия до продолжения, пройдите связанную выше процедуру с техническим помощником.

**Шаг завершён, когда:** помощник показал семь установленных названий и правильное место внутри проекта. Распаковка ZIP, регистрация каталога плагинов или дружелюбное «готово» сами по себе не доказывают установку.

## 6. Откройте новый разговор и проверьте скиллы

1. Начните **новый разговор в том же проекте Business Assistant**. Если скиллов нет, полностью закройте и снова откройте приложение, затем этот проект.
2. В Codex откройте **Skills** в боковой панели, если этот пункт доступен, либо элемент выбора скиллов вашей версии. Можно явно попросить применить **`de-business-kit`**. В Codex CLI/IDE выбор открывается через `/skills` или `$`; элементы настольного приложения могут отличаться.
3. В Claude Code введите **`/`** или откройте **+ → Slash commands**, найдите **`de-business-kit`**. Для этой установки отдельных скиллов выберите **`/de-business-kit`**. При установке плагина команда имеет другое составное имя.
4. Попросите: **«Проверь, какие скиллы German Business Kit действительно доступны в этом проекте. Перечисли названия и отметь, если чего-то не хватает».**

Должны быть доступны:

| Название скилла | С чем помогает |
| --- | --- |
| `de-business-kit` | Начать, продолжить, выбрать следующую задачу |
| `de-business-start` | Подготовить и открыть деятельность |
| `de-business-operations` | Предложения, счета и текущая переписка |
| `de-business-accounting` | Документы и учётные записи |
| `de-business-tax` | Налоговые вопросы, отчёты и письма Finanzamt |
| `de-business-services` | Банк, страхование, программы и доступ к сервисам |
| `de-business-changes` | Изменения, найм, пауза и закрытие |

Если хост не может подтвердить обнаружение скиллов, попросите проверить пути установки и назвать это ограничение. Прочитать названия папок полезно для диагностики, но это не доказывает подключение скиллов в хосте. Не включайте один набор одновременно как отдельные скиллы и как плагин.

**Шаг завершён, когда:** хост показывает установленные скиллы и может загрузить `de-business-kit` в новом сеансе. Семь скиллов используют один контекст бизнеса; семь чатов и семь настроек не нужны.

## 7. Попробуйте одну небольшую задачу

Отправьте вымышленный пример:

> Используй de-business-kit. Я только пробую помощника на вымышленном примере: хочу начать работать переводчиком в Германии. Пока не знаю, с чего начать. Помоги выбрать один небольшой первый шаг.

Полезный результат — одно понятное действие и вопросы только о действительно нужных фактах. Для такого вопроса не требуется выбирать бухгалтерскую программу, создавать полное пространство бизнеса или загружать личные документы. Первый ответ не доказывает завершённую регистрацию или налоговую проверку.

Можно продолжать на русском или английском. Для собственной задачи опишите желаемый результат: разобраться с письмом, подготовить форму, упорядочить документы, сравнить сервисы или спланировать изменение. Для юридических и налоговых выводов помощник должен проверять актуальные официальные источники и отмечать неизвестное.

**Шаг завершён, когда:** вы понимаете результат и следующее действие. Если ответ слишком технический, скажите: **«Объясни простыми словами и дай только следующий шаг».**

## 8. Сохраните работу, когда это понадобится

Для продолжающейся задачи попросите:

> Помоги выбрать отдельную приватную папку бизнеса и сохранить туда понятный результат и следующее действие. Если рабочее пространство уже есть, продолжи его. До использования настоящих личных документов объясни, какое содержимое будет отправляться ИИ-сервису.

В **Business Assistant** хранятся скиллы; в отдельной папке, например **Мой бизнес**, — ваши записи. Не помещайте документы бизнеса в каталоги скиллов и репозитории исходников. Создавайте новое рабочее пространство только по необходимости и в новой пустой папке; не инициализируйте существующие записи повторно. Папки «Документы» и «Рабочий стол» могут синхронизироваться с облаком — проверьте, соответствует ли это вашему выбору приватного хранения.

В следующий раз откройте тот же проект помощника и попросите: **«Продолжи с сохранённого результата в [папка бизнеса]. Покажи следующее действие».** При необходимости разрешите доступ к этой отдельной папке. Выбранная существующая бухгалтерская программа остаётся основным местом учёта; простой вопрос не заставляет принимать это решение.

**Далее:** [первая рабочая задача](start.ru.md), [меню задач](tasks.ru.md), [руководство на каждый день](user-guide.ru.md).

## Ручной вариант

Используйте его после проверки архива, описанной выше, если помощник не может скопировать файлы. Для копирования команды терминала не нужны; файловый менеджер не проверяет пакет и не выполняет проверки конфликтов установщика.

1. Распакуйте ZIP в новую папку: Windows → правая кнопка → **Извлечь всё…**; Mac → двойной щелчок по ZIP.
2. Откройте `codex/plugins/de-business-kit/skills` либо `claude/plugins/de-business-kit/skills` внутри распакованного содержимого. Файловый менеджер может добавить внешнюю папку с именем ZIP.
3. В **Business Assistant** создайте **`.agents/skills`** для Codex или **`.claude/skills`** для Claude Code. Это две вложенные папки. На Windows при необходимости включите **Вид → Показать → Скрытые элементы**. На Mac нажмите **Command+Shift+.**, чтобы увидеть скрытые элементы; если Finder отказывается создать папку с точкой в начале, попросите помощника или специалиста создать именно это место назначения. Не заменяйте его папкой без начальной точки.
4. Скопируйте **все семь папок `de-business-*` вместе**, со всем содержимым. Если хотя бы одна целевая папка уже есть, остановитесь; не объединяйте и не перезаписывайте её. Используйте инструкцию обновления по ссылке ниже.
5. Проверьте структуру и вернитесь к шагу 6. Нельзя копировать только `SKILL.md`, только `de-business-kit` или лишнюю внешнюю папку `skills`.

```text
Business Assistant/
└── .agents/                  ← Codex; для Claude Code используйте .claude
    └── skills/
        ├── de-business-kit/
        │   ├── SKILL.md
        │   ├── assets/
        │   ├── guides/
        │   ├── references/
        │   └── scripts/
        ├── de-business-start/SKILL.md
        ├── de-business-operations/SKILL.md
        ├── de-business-accounting/SKILL.md
        ├── de-business-tax/SKILL.md
        ├── de-business-services/SKILL.md
        └── de-business-changes/SKILL.md
```

## Если что-то не получается

| Что происходит | Следующий шаг |
| --- | --- |
| Нет раздела Codex/Code | Проверьте официальное приложение, совместимость компьютера, доступ аккаунта и политику организации. Обычный чат — другой режим. |
| Скачанные файлы недоступны | Укажите точные пути и разрешите только нужный локальный доступ. Не вставляйте пароли или токены. |
| После установки нет скиллов | Проверьте выбранный локальный проект, точку в начале пути, семь папок и новый сеанс. Исключите вложение `skills/skills`. |
| Приложение предлагает установить Python или изменить защиту | Остановите этот шаг и используйте штатное копирование либо разрешённую помощь; базовая установка скиллов этого не требует. |
| Место назначения занято | Сохраните его. Следуйте [инструкции обновления](https://github.com/ilyafedotov-ops/german-business-skills/blob/main/docs/distribution.ru.md), сохраняя изменения и документы бизнеса. |
| Нет доступа к банку, почте или Lexware | Установка скиллов не подключает сервисы. Продолжите на вымышленном примере или выбранном локальном экспорте; каждое подключение проверяется отдельно. |
| Команда завершилась ошибкой | Сохраните сообщение, версию приложения, ОС и номер шага. Попросите помощь с этим шагом; уберите личные данные перед публичной публикацией. |
