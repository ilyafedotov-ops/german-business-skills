# Start here

**English** · [Русский](start.ru.md) · [Deutsch](start.de.md)

German Business Kit is a system of skills for entrepreneur assistance: preparing to start, forms, questions, services, daily work and reporting. Development and closure are intended areas, but preparation guidance is available; real execution needs separate acceptance. Describe the result you need in ordinary language. A simple question requires neither the local application nor workspace creation; tools are introduced for the task.


You can directly select `de-business-start`, `de-business-operations`, `de-business-accounting`, `de-business-tax`, `de-business-services` or `de-business-changes`. The general `de-business-kit` helps select the next action. See the [map and shared resources](../references/lifecycle.md). Install the complete bundle; keep one profile.

## 1. Open your assistant

Use an existing Codex or Claude Code installation with access to your chosen local folder. If German Business Kit is installed, select it from the available skills. If you have only downloaded the project, extract it and ask:

> I downloaded German Business Kit. Help me inspect and connect this skill in my app. First explain which files will be installed and where. Do not install Python or change my computer's security settings.

Point to the extracted folder if the assistant cannot see it. Downloading a ZIP does not install the skill. If your app/organization restricts file access or installation, ask for an allowed route; do not disable protections.

## 2. Choose your situation

Copy **one** request and replace only facts you know.

| Situation | What to say |
| --- | --- |
| You already have records | “Start in English. My records are in a folder / Gmail / accounting software. First show what can be accessed and organized, then help select relevant files. Do not send anything or change the source yet.” |
| You are starting a business | “Help me prepare the next step for starting my activity in Germany. I plan to … Account for any other activity I already have. Ask only what affects the next step.” |
| You have worked here before | “Continue in my existing workspace. Show what is done, what needs attention and the next action. Do not start over.” |
| You want to try it first | “Show a small fictional example in a separate practice folder. Explain the result without technical terminology.” |

A simple question does not require a workspace. The demonstration is optional too: begin with your actual task when its scope and access are clear.

## 3. Choose where work is saved

For ongoing work choose a private folder separate from the downloaded project, installed skill and Git repositories. Give it a clear name, such as “My business.” Resume that folder if it already exists.

New workspaces can use English, Russian or German names. The English layout contains **Inbox, Documents, Accounts, Taxes, Business** and `START-HERE.md`. You can change conversation language later without renaming folders. Existing workspaces keep their older structure.

The assistant will establish where authoritative accounts are kept: existing software or local records. You can defer that choice while organizing documents. It must not choose your tax regime or create parallel accounts on your behalf.

## 4. Complete one small task

Start with one document or a small selected batch. Before real personal data, establish where selected content may be processed: a local folder does not mean a local AI model. Enter passwords, certificates and verification codes only in the official authentication flow.

Ask:

> Show what you found, what you saved, what is missing and where I can open a readable result. Do not call a document reviewed or submitted without evidence.

A useful first result: the file is found and preserved, its explanation can be read, and the next action is clear. If a tool is unavailable, the assistant should identify the specific unfinished step and continue available preparation.

## 5. Save a continuation point

> Save a short result and next action in my workspace. Link the file. I want to continue from here next time.

Return to the same folder and ask to continue. You do not need to remember commands or repeat the entire history. A deadline reminder is only configured when an actual reminder tool confirms it.
