# Помощь внутри ELSTER и бухгалтерской программы

[English](assisted-services.en.md) · **Русский**

Помощник может помогать работать в сервисе, а не только объяснять его. Например:
**«Помоги заполнить черновик; проверю и отправлю я сам».** Если доступны разрешённые
инструменты браузера или управления компьютером, он может внести поддерживаемые
поля, проверить результат и провести через оставшиеся шаги. Возможности проверяются
для вашего приложения, аккаунта и конкретной операции.

Начните с [инструкции вызова скилла](user-guide.ru.md#как-вызвать-скилл). Для доступа к сервису выберите `de-business-services`; для задачи ниже назовите `de-business-operations`.

## Когда включать браузер или управление компьютером

German Business Kit предоставляет бизнес-инструкции. Настоящие инструменты,
вспомогательные скиллы и разрешения предоставляет ваш ассистент. Включение одного
скилла не подключает банк, не открывает сеанс браузера и не разрешает изменения.

| Задача | Полезная возможность |
| --- | --- |
| Найти актуальные правила или прочитать публичную справку | Web search/чтение страниц; интерактивный браузер и доступ к рабочему столу обычно не нужны. |
| Читать или менять записи через существующее поддерживаемое подключение | Подходящий коннектор с ограниченными правами; для уже поддерживаемой операции дополнительный браузер не нужен. |
| Открыть поддерживаемый сайт, проверить черновик, заполнить согласованные поля или получить выбранную выгрузку | Интерактивный браузер; проверьте поддержку конкретного сайта, аккаунта, сохранения/скачивания/загрузки и данных. |
| Работать в установленном приложении без подходящего коннектора/браузера | Управление компьютером, только если хост поддерживает это приложение, ОС, действие и данные. |
| Разобрать вопрос или уже предоставленный файл | Чат и инструменты документов; браузер/экран необязательны. |

**Перед чувствительными аккаунтами проверьте допустимость маршрута.** Сейчас
Anthropic настоятельно не рекомендует использовать встроенный браузер или
интеграцию Chrome для финансовых аккаунтов, медицинской информации и персональных
данных других людей; также не рекомендует давать управление банковскими,
медицинскими и государственными приложениями. Некоторые сайты заблокированы.
Не обходите ограничение браузера через управление рабочим столом. Для реального
ELSTER, банка или клиентских записей сначала проверьте ограничения хоста и условия
обработки; если UI-доступ не подходит, используйте допустимое подключение,
минимизированный файл или ручной маршрут с подсказками. Подготовить значения и
проверить доказательства можно без управления порталом.
[Обработка данных](user-guide.ru.md#ограничения-ai-и-ваши-данные).

### Включите возможность в своём приложении

Эти пути из документации провайдеров проверены **26 октября 2026**. Названия,
доступность и правила организации могут различаться; ассистент должен проверить
фактические возможности, а не обещать одинаковый переключатель каждому.

| Приложение/маршрут | Настройка, если доступна |
| --- | --- |
| Codex / ChatGPT desktop, встроенный браузер | Попросите использовать **@Browser**. У него отдельный профиль; доступ настраивается в **Settings → Browser → Agent permissions**. Сейчас автоматическая загрузка файлов не поддерживается: выполните её вручную или используйте другой допустимый маршрут. [Браузер](https://learn.chatgpt.com/docs/browser). |
| Codex с существующим сеансом браузера | **Settings → Computer Use → выберите браузер → Install** официального расширения; вернитесь и проверьте **Manage**, затем выберите **@Chrome**, **@Edge** или поддерживаемый браузер в разговоре. [Расширение](https://learn.chatgpt.com/docs/chrome-extension). |
| Codex с установленными приложениями | **Plugins → Computer Use → Install plugin/Enable**, включите server и skill, затем **Try now**. Проверьте доступ к приложениям в **Settings → Computer use** и запрашиваемые разрешения ОС. [Computer Use](https://learn.chatgpt.com/docs/computer-use). |
| Claude Cowork, браузер | Доступный встроенный браузер не требует расширения. Выберите его в **Settings → Cowork → Preferred browser**. Для существующих вкладок Chrome: **Customize → Connectors → Claude in Chrome → Configure**, затем включите в разговоре. [Встроенный браузер](https://support.claude.com/en/articles/16607400-use-the-built-in-browser-in-claude-cowork), [настройка Chrome](https://support.claude.com/en/articles/12012173-get-started-with-claude-in-chrome). |
| Claude с установленными приложениями | Текущая beta: Pro/Max на поддерживаемых macOS/Windows desktop. Если пункт доступен: **Settings → Capabilities** или **System → This computer → Enable computer use**; проверьте доступ к приложениям. Согласно текущей документации, Team/Enterprise эту native-функцию не поддерживают. [Настройка и ограничения](https://support.claude.com/en/articles/14128542-let-claude-use-your-computer-in-cowork). |

Начните с минимального доступа для задачи. Вход, MFA и сертификаты остаются в
официальном процессе под вашим управлением; секреты в чат не передают. Содержимое
браузера, снимки экрана и результаты инструментов могут получать AI-провайдеры.
Проверьте запрашиваемые права и скройте посторонние чувствительные данные перед
доступом к экрану. Включение управления не разрешает отправку, покупку, платёж или
подачу: действуют рамки задачи и оставленные за вами финальные действия.
Доступ можно отключить в хосте. Не отключайте защиту и не устанавливайте случайные
инструменты.

Сначала попробуйте публичную или вымышленную задачу:

> Используй de-business-services. Проверь, можешь ли открыть и прочитать эту публичную страницу справки доступными инструментами браузера. Не входи в аккаунт, не заполняй формы и ничего не меняй. Скажи, что действительно увидел и поддерживает ли инструмент нужное мне дальнейшее взаимодействие.

Ассистент должен прочитать инструкции установленного вспомогательного скилла,
если он есть, и проверить небольшую разрешённую операцию после настройки.
**Настроено** не означает **проверено для этой операции**. Если инструмента нет
или вы не хотите его включать, можно подготовить таблицу полей, разобрать выбранную
выгрузку или пройти ручные шаги. Python, Playwright и среда разработчика не нужны.

## 1. Скажите, что хотите закончить

Назовите сервис и результат: подготовить форму регистрации, изменить черновик
счёта или скачать документы за октябрь. Если черновик уже есть, укажите его.
Вам не нужно разбираться в API, коннекторах и схемах файлов.

> Используй de-business-operations. Я использую Lexware Office в браузере. Помоги исправить существующий черновик
> счёта. Внеси подтверждённые сведения и покажи предварительный просмотр.
> Окончательно оформлю и отправлю я сам. Перед изменениями объясни, к чему есть доступ.

Помощник проверяет инструменты и актуальные инструкции продукта. Подходящее
существующее подключение можно использовать для поддерживаемых действий;
браузер — для того, что коннектор не умеет. Отсутствие API не означает
автоматическую покупку более дорогого тарифа или смену бухгалтерской программы.

## 2. Откройте правильный аккаунт

Помощник объяснит способ работы и недостающий доступ. Если нужен вход, выполните
его самостоятельно на официальной странице, включая MFA, сертификат или CAPTCHA.
Затем сообщите о готовности. Не вставляйте в разговор пароли, TAN, ключи API
и файлы сертификатов ELSTER.

До работы с настоящими личными документами и снимками экрана выясните, какое
содержимое может получить ИИ-сервис. Локальный браузер не означает локальную
обработку ИИ. После вашего возвращения помощник проверит аккаунт/компанию и
черновик. Если нужна новая интеграция браузера, он объяснит поддерживаемую
настройку и права до предложения включить её; устанавливать её незаметно нельзя.

## 3. Подготовьте и заполните черновик

Помощник соберёт только нужные для задачи факты и подготовит значения с основаниями.
Неизвестное останется открытым. Он может заполнить разрешённые поля по настоящим
видимым названиям, проверить введённое и сохранить черновик, если это поддерживается.
Ввод может автоматически сохраняться в сервисе; этот эффект должен входить в
согласованный объём работы до начала ввода. Повторно одобрять каждое поле при
уже разрешённой работе не требуется.

Если информации не хватает, помощник продолжит независимые поля и задаст понятный
вопрос. Нельзя придумывать налоговый номер, прогноз оборота, налоговый выбор или
формулу ради обязательного поля. Для расчётов нужны проверенные источники и
подходящий официальный инструмент либо выбранная программа; недоступный расчёт
остаётся явно обозначенным пробелом.

**Пример для ELSTER:**

> Помоги подготовить анкету налоговой регистрации моей деятельности в Германии.
> Проверь правильную форму и мой существующий аккаунт. Внеси известные факты в
> черновик, где позволяют инструменты; спроси о недостающих решениях. Войду и
> отправлю после проверки я сам. Также объясни, нужна ли моей деятельности
> отдельная Gewerbeanmeldung и есть ли в моём муниципалитете объединённый путь.

Анкета налоговой регистрации ELSTER и муниципальная Gewerbeanmeldung — разные
процедуры. Путь зависит от деятельности и места; заполненная налоговая анкета
сама по себе не доказывает регистрацию Gewerbe.

## 4. Проверьте вместе, подтвердите самостоятельно

Помощник покажет внесённые данные, форму/документ/год и получателя, предупреждения,
предложенные налоговые решения и вложения. Он различает **сохранить черновик**,
**предпросмотр**, **окончательно оформить**, **отправить** и **подать**.

Если вы решили закончить вручную, это действие остаётся за вами. Помощник должен
указать место сохранённого черновика и наблюдавшийся элемент управления для
готового результата. Если обязательное значение или предупреждение не разрешено,
он объяснит недостающее до отправки. Другой аккаунт или существенная правка
требует повторной проверки затронутых данных.

После действия вернитесь в разговор. Помощник может проверить статус или
несекретную квитанцию, если это доступно. Ваше «готово» фиксируется как сообщение
пользователя до подтверждения доказательствами. При неясном результате он
проверит историю, прежде чем предлагать повтор.

## Выгрузка и загрузка данных

> Скачай выбранные документы за октябрь из моей бухгалтерской программы.
> Проверь фильтр дат и исходные форматы. Не фиксируй проводки, не оформляй
> черновики окончательно и ничего не передавай консультанту. Если экспорт
> не позволяет избежать этих эффектов, объясни альтернативу до продолжения.

Некоторые экспорты меняют записи или передают данные другим сторонам. Помощник
проверит путь, выборку и эффекты, затем реальные скачанные файлы и неполноту
охвата. PDF-предпросмотр не обязательно является исходным XML счёта. Импорт —
отдельная запись: до запуска проверяются место назначения, соответствие полей
и обработка дублей. Экспорт/импорт не меняет основное место учёта незаметно.

Для **Lexware Office** редактирование существующего черновика счёта может
потребовать браузер: текущая документация API не описывает обновление счёта
и скачиваемый файл счёта для черновика. Помощник не должен оформлять счёт
окончательно ради PDF. Эти сведения перепроверяются при использовании; см.
[датированную запись официальных источников](../references/assisted-services-sources.md).

## Если помощник не может работать со страницей

Он должен назвать недостающую возможность и закончить доступную подготовку.
Например: «Я могу подготовить значения, но не загрузить вложение в этом браузере.
Используйте показанный на экране элемент загрузки, выберите этот файл и вернитесь,
чтобы я проверил результат». Можно подготовить короткую таблицу полей или
изучить выбранный локальный экспорт. Для такого запасного пути не требуется
установка Python или отключение защиты.

Сохраните черновик/ссылку и следующее действие для продолжения в другом сеансе.
Набор содержит рабочие инструкции, а не встроенный коннектор ELSTER/Lexware
или гарантию поддержки всех экранов. Проверены только локальные примеры Lexware; живая приёмка
ещё не выполнена. [Выбрать задачу](user-guide.ru.md#первая-задача) · [Помощь на каждый день](user-guide.ru.md).
