# Choose the task you need

[English](tasks.en.md) · [Русский](tasks.ru.md) · [Start](start.en.md)

Describe the desired result. The assistant selects the relevant skill and reuses
known facts; you can select a skill directly too. A question or draft does not
require an accounting setup or the desktop application. Share only the evidence
needed for your task through an appropriate private channel.

| Your request | What you can receive now | What establishes the later outcome |
| --- | --- | --- |
| “I want to start this activity; help me prepare.” | A launch plan, decisive questions, researched route and a form worksheet using known facts | Actual registration/portal outcomes, each recorded separately |
| “Prepare a proposal or invoice from these agreed terms.” | A recipient draft and private check of missing terms, treatment and format; existing software keeps its numbering | Actual issue/delivery and later payment evidence |
| “Help answer this letter.” | A factual explanation, recipient-language reply and separate private review, even without portal access | Actual sending evidence and the later response; a draft changes neither |
| “Prepare my month/year in my existing accounting software.” | An evidence inventory, discrepancies, readiness report and inputs for the selected calculation/form tool | Actual tool output, review and submission evidence; local cash totals alone are insufficient |
| “I want to hire, move, pause or close one activity.” | A before/after plan with dependencies, prepared materials and matters that must remain open | Each authority/service outcome and preserved access/history |
| “Check whether we can retrieve these records from my service.” | A bounded access check through available tools, or inspection of a supplied export | Actual scope/readback; a documentation link is not a connection |
| “Continue the work we saved.” | The latest result, changed evidence, unresolved question and next action | Saved task/evidence state; no new profile or repeated setup |

For a simple question, expect a direct answer. For substantial work, expect a
readable file with known facts, sources, unresolved matters and one next step.
You should not need to understand JSON or repeat a long prompt. A private working
sheet is never attached automatically to a customer or authority reply.

## Continue with new evidence

Open the same folder or saved result and say, for example:

> Here is the statement we were missing. Compare it with the saved reply, keep the old version, and update the draft. Do not send it yet.

The assistant should check the new evidence, preserve the previous version and
explain what changed. If the existing protected writer is unavailable, it can
save a readable note but must identify the register update that did not happen.
A temporary practice folder is not durable business storage. Choose a private
permanent folder when you want to keep work between sessions.

## When the local application helps

The application handles selected workspace operations: intake, review, limited
cash records, filing evidence and backup/restore. Use it for those operations
when helpful. Launch planning, letters, service research and change plans can be
completed with skills and readable files. These guides do not add new GUI screens.

An unavailable tool should leave a precise next action, not an invented success.
No live connector, payroll calculation, official transmission or reminder is
established by saving a worksheet. An external action uses the reviewed target,
exact files and matching authorization. A manual route can still support your
own accounting and reporting without making an accountant the mandatory endpoint.
