# Entrepreneur lifecycle and skill ownership

The complete bundle has seven direct entry points. Select only the relevant
skill; the general router is optional. All use the same
[shared context and execution contract](shared-context.md), profile, tasks,
evidence and validated writers. A skill switch does not launch another agent.

| Outcome | Owner | Main references |
| --- | --- | --- |
| Start, continue or resolve a mixed request | [Kit](../SKILL.md) | [Onboarding](onboarding.md), [intake](intake.md), [continuation](continuation.md), [workspace](workspace.md) |
| Prepare and register an activity | [Start](../../de-business-start/SKILL.md) | [Launch plan](launch-plan.md), [formation](formation.md), [classification](classification.md), [forms](forms.md) |
| Customer documents and daily work | [Operations](../../de-business-operations/SKILL.md) | [Operations](operations.md), [correspondence](correspondence.md), [document authoring](document-authoring.md), [payments](payments.md) |
| Review, reconcile and account for records | [Accounting](../../de-business-accounting/SKILL.md) | [Accounting workflow](accounting-workflow.md), [bookkeeping](bookkeeping.md), [monthly workflow](monthly-workflow.md) |
| Tax questions, reporting and authority replies | [Tax](../../de-business-tax/SKILL.md) | [Tax preparation](tax-consultant.md), [estimates](tax-estimates.md), [annual workflow](annual-workflow.md), [international](international.md) |
| Select services and verify access | [Services](../../de-business-services/SKILL.md) | [Providers](providers.md), [insurance](insurance.md), [connections](connections.md), [existing data](existing-data.md) |
| Changes, hiring preparation, pause or closure | [Changes](../../de-business-changes/SKILL.md) | [Changes](changes.md), [employment preparation](employment.md), [lifecycle sources](lifecycle-sources.md), [recovery](recovery.md) |

An ordinary question does not require GUI installation, workspace creation or an
accounting choice. Keep several activities in the same entrepreneur profile;
they can be at different lifecycle stages without adding a new persisted enum.

The references provide agent-led workflows. They do not themselves establish
registration, legal/tax correctness, payroll, complete statutory accounting,
provider access or transmission. Verify current sources, actual tools and each
observed result. A manual route can be useful without being an automated connector.
Keep prepared, reviewed, authorized, sent and authority-confirmed outcomes distinct.

Shared resources remain in `de-business-kit`; membership is recorded in
[the catalog](../assets/skill-set.json). Install all seven skills together.
Changing the bundle does not migrate private workspaces or replace chosen external
accounting software. Never invent tax formulas or make accountant handoff the
mandatory endpoint of self-managed reporting.

For durable results, use the EN/RU launch plan, customer case, annual readiness,
change plan and connection-check worksheets linked from their workflow references.
They are authoring aids using existing evidence/tasks, not official forms or new
state registers. User-facing examples are in the [English task guide](../guides/tasks.en.md)
and [Russian task guide](../guides/tasks.ru.md).
